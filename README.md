# VeloCopy

把一批文件拷走，也把复制过程看清楚。选择来源和目标后，查看复制进度，按需暂停和恢复，并等待 SHA-256 校验完成。

Copy local file batches on Mac with visible progress, pause and resume, and SHA-256 verification.

**平台 / Platform:** Mac
